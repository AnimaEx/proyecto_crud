
# Sistema de Gestión de Inmuebles

Proyecto académico desarrollado con Python y Django, utilizando PostgreSQL como sistema de gestión de bases de datos.

## Descripción

Aplicación web orientada a la gestión y consulta de propiedades inmobiliarias.

El proyecto permite presentar información sobre inmuebles disponibles para arriendo mediante una interfaz organizada y accesible.

## Tecnologías utilizadas

- Python
- Django
- PostgreSQL
- HTML
- CSS

## Características

- Visualización de propiedades inmobiliarias.
- Información de precios, ubicación y características de los inmuebles.
- Interfaz de búsqueda con filtros por tipo de propiedad, región y comuna.
- Opciones de registro e inicio de sesión.
- Integración con una base de datos PostgreSQL.

## Instalación

Las dependencias se encuentran en `proyecto_inmuebles/requirements.txt`.

El archivo `proyecto_inmuebles/.env.example` contiene las variables de entorno necesarias para configurar Django y PostgreSQL.

Para ejecutar la aplicación localmente se requiere configurar una base de datos PostgreSQL y las variables de entorno correspondientes.
